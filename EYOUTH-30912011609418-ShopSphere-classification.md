# Cloud Service Classification — EYOUTH-30912011609418-ShopSphere

## 1. Vercel (Frontend Hosting)

**Classification:** PaaS (Platform as a Service)

**Reason:** We deploy only the application code; Vercel manages the underlying runtime, build pipeline, global CDN, automatic HTTPS, and serverless infrastructure with no server or OS management on our side.

## 2. Vercel (Backend Hosting)

**Classification:** PaaS (Platform as a Service)

**Reason:** We deploy the Express/Node.js application as a serverless function; Vercel handles the runtime environment, function execution, scaling, SSL termination, and deployment infrastructure without any access to or management of the underlying servers.

## 3. Supabase (PostgreSQL Database)

**Classification:** SaaS (Software as a Service)

**Reason:** Supabase provides a fully managed, hosted PostgreSQL database with a web dashboard, connection pooling, and API access; we configure and use the database through their platform without managing any server, operating system, or database installation.
